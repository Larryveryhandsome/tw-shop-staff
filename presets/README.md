# 產業範本

| 代號 | 產業 | 單位 | 預設開啟的功能 | 單位成本範例 |
|---|---|---|---|---|
| `bento` | 便當／小吃店 | 個 | 食安、團體訂單開發、外送、行銷、新聞、日誌 | 排骨便當、雞腿便當、素食便當 |
| `drink` | 飲料店 | 杯 | 食安、團體訂單開發、外送、行銷、新聞、日誌 | 珍珠奶茶、鮮奶茶、四季春 |
| `breakfast` | 早餐店 | 份 | 食安、團體訂單開發、外送、新聞、日誌 | 火腿蛋吐司、蘿蔔糕加蛋、大冰奶 |
| `salon` | 美髮／美甲 | 位 | 行銷、新聞、日誌 | 洗剪、染髮、凝膠美甲 |
| `retail` | 零售門市 | 件 | 行銷、新聞、日誌 | 手工皂禮盒、在地醬油、明信片 |

每個範本有三個檔：

- `store.toml`：店家設定，包括店名、支出類別、營收單位、功能開關。套用後會變成 `config/store.toml`。
- `ledger.toml`：股東帳務設定，包括股東、期初、系統外手記、單位成本。套用後會變成 `data/ledger.toml`。
- `demo.toml`：示範假資料，包括示範員工與班表、每天營收範圍、支出項目、開發名單、教育訓練。

各行業怎麼選範本、怎麼設定，見 [百工百業適用指南](../docs/industries.md)。

## 怎麼用

```bash
python tools/use_preset.py            # 列出範本
python tools/use_preset.py drink      # 套用飲料店範本
python app/seed_demo.py --preset drink   # 建一家示範飲料店（全部是假資料）
python app/app.py                     # 打開 http://localhost:8402
```

`seed_demo.py` 只會建立新的資料庫，已經有 `app/data/crm.db` 就會停下來，不會蓋掉你的資料。

## 注意

- 示範班表都依勞基法排：每週休兩天、連續工作 4 小時以內就休息、時薪不低於基本工資。系統會檢查這些規則，有違反就提醒。
- 美業的設計師抽成、零售的業績獎金，目前請用老闆頁「薪資調整」逐月加給。之後會做成正式的抽成規則。
- 單位成本只是範例數字，請換成你自己的進貨價。
- 想新增產業範本，複製一個資料夾改內容就好。歡迎送 PR 分享你的產業範本。
