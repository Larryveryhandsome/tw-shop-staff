# 金鑰與外部帳號：哪些需要、怎麼申請

**先講結論：這個系統不需要任何金鑰就能完整使用**（打卡、計薪、記帳、核銷、股東網站都能用）。下面三項都是選用，需要時再看。

| 項目 | 用在哪 | 需要自己申請嗎 | 費用 |
|---|---|---|---|
| 手機推播的 VAPID 金鑰 | 手機收到通知（遲到提醒、公告） | **不用申請**，系統第一次啟動自動產生 | 免費 |
| Cloudflare 帳號（Tunnel） | 讓員工用手機從外面連進來 | 要註冊帳號、要有網域 | 帳號與 Tunnel 免費；網域約每年數百元（依網域後綴） |
| AI 服務金鑰 | 行銷草稿、每週新聞（由外部工具產生） | 看你用哪個 AI；本系統不內建、不要求 | 依該服務計費 |

以下價格與介面可能改版，原則上請以各官方網站為準。

---

## 一、手機推播（VAPID）：不用申請，只要裝套件

VAPID 是瀏覽器推播用的一對金鑰。你不用去任何網站申請，系統會自己做。

1. 在專案資料夾執行：

   ```bash
   pip install -r requirements.txt
   ```

2. 重新啟動系統（Windows 雙擊 `停止.vbs` 再雙擊 `啟動.vbs`）。
3. 第一次啟動時會自動產生私鑰檔 `app/data/vapid_private.pem`（示範店在 `data/demo/` 底下）。**這個檔案不要上傳、不要分享**；刪掉它之後所有人要重新開通知。
4. **怎麼確認成功：** 員工用手機打開網站後，會被問「是否允許通知」，按允許；老闆發一則公告，員工手機會跳通知。
5. 常見問題：
   - 沒有跳出「是否允許通知」：沒裝 `cryptography`（步驟 1），或網址不是 HTTPS（見下一節）。
   - 之前按了「不允許」：到手機的「設定 › 通知」或瀏覽器網站設定把通知打開。
   - iPhone：要先用 Safari「加入主畫面」，再從主畫面的圖示打開，才收得到。
   - 要換金鑰：刪掉 `vapid_private.pem` 重啟，所有員工需要重新允許通知。

## 二、Cloudflare Tunnel：讓手機從外面連進來（選用）

只在店裡 Wi-Fi 用的話不需要。要讓員工在店外也能連、或要用手機 GPS 打卡與推播（需要 HTTPS），才需要。

1. 準備一個網域（可在 Cloudflare Registrar 或其他網域商購買）。
2. 到 https://dash.cloudflare.com/sign-up 註冊帳號（免費方案即可），登入後按「Add a site」，輸入你的網域，選 Free 方案，照畫面指示把網域的 Nameserver 改成 Cloudflare 給的兩個。
3. 左側進入 **Zero Trust**（第一次會要你取名並選免費方案；可能要求綁定付款方式但 Free 不收費）→ **Networks › Tunnels › Create a tunnel** → 選 Cloudflared → 取個名字。
4. 依畫面指令在店裡電腦安裝 `cloudflared` 並貼上它給的安裝指令（Windows 可選擇安裝成服務，就會開機自動啟動）。
5. 在 **Public Hostname** 新增兩筆：`staff.你的網域` 指到 `http://127.0.0.1:8402`、`ledger.你的網域` 指到 `http://127.0.0.1:8403`。
6. 把網址填進設定檔 `config/store.toml`（`[store] public_url` 與 `[ledger] public_url`），詳見 [deploy.md](deploy.md)，改完重新啟動。
7. **怎麼確認成功：** 用手機行動網路（不要連店裡 Wi-Fi）打開 `https://staff.你的網域`，看得到登入頁、網址列有鎖頭。
8. 常見錯誤：
   - 「Error 1033」或打不開：店裡電腦的 cloudflared 沒在跑，檢查服務是否啟動。
   - 「502 Bad Gateway」：系統本身沒啟動，或 Public Hostname 的埠號填錯（員工 8402、股東 8403）。
   - 網域一直是 Pending：Nameserver 還沒生效，通常數分鐘到一天。
   - 登入後馬上被登出：`public_url` 沒改成 https 網址，或反向代理沒帶 `X-Forwarded-Proto`。

## 三、AI 服務金鑰：本系統不內建（選用）

「行銷」與「新聞」模組只讀取**交接資料夾裡的檔案**，不會呼叫任何 AI 服務，所以**不需要把任何 AI 金鑰填進本系統**。要不要用 AI 產生草稿、用哪一家，都由你決定：

- 行銷草稿：格式見 [marketing.md](marketing.md)。你可以用任何 AI 對話工具，叫它照格式產生檔案，放進交接資料夾，老闆核准才發。
- 每週新聞：叫 AI 照格式產生 `新聞.json`，再執行 `python tools/import_news.py 新聞.json` 匯入。
- 若你自己另外寫程式呼叫某家 AI，金鑰請放在**那支程式自己的設定或環境變數**裡，不要放進本專案資料夾、不要上傳 git。申請方式請看該服務官方文件（一般流程是：註冊 → 開發者主控台 → 建立 API key → 只顯示一次，立刻複製存好）。

## 金鑰安全提醒

- `app/data/`、`data/`、任何 `.pem`、`.env` 都不要進 git、不要放雲端共享資料夾。
- 金鑰外洩就立刻換：推播刪 `vapid_private.pem`；Cloudflare 在 Tunnel 頁面重新產生 token；AI 服務在其主控台刪除舊 key 另建新的。
