# 百工百業適用指南：你的店適不適合、要怎麼設定

標示「✅ 已實測」的行業，都在 [`tests/test_industries.py`](../tests/test_industries.py) 裡完整跑過一個月（2026 年 9 月，含中秋、教師節兩天國定假日）。流程是：開系統 → 老闆看薪資 → 夥伴手機打卡 → 店長記帳 → 老闆核銷 → 印簽收單 → 產生股東頁。薪資另外用照勞基法條文寫的算法對答案，結果一致。

「🔸 未實測」是依實測行業推論的建議設定，原則上可以用，但還沒有專門的測試。

- 外送平台抽成可以寫進 `data/ledger.toml` 的單位成本 `fees`，股東頁會算出抽成後的毛利。

## 四、目前不建議用這套的

| 行業 | 原因 | 建議 |
|---|---|---|
| 到府清潔、水電、搬家等派工型 | 核心是「接單 → 派工 → 現場回報」，不是門市打卡 | 等姊妹專案 **tw-dispatch-kit**（到府服務接單派工，規劃中） |
| 房仲、保險、汽車銷售等業務型 | 核心是客戶名單、案件追蹤 | 等姊妹專案 **tw-office-hub**（業務型辦公室中控台，規劃中） |
| 工廠、營造 | 常用變形工時、輪班津貼、外籍移工，本系統還沒支援 | — |
| 診所、托嬰中心 | 醫事人員、托育人員另有專法與排班規定 | 可以只用記帳和股東頁，計薪請另外確認 |
| 多家分店要集中管理 | 一套系統對應一家店 | 每家店各裝一套；股東頁各自產生 |
| 需要串 POS、電子發票 | 目前營收是店長每天手記並拍日結單 | 歡迎貢獻 POS 匯入 |

## 五、所有行業都要知道的限制

- **還沒做的勞基法項目**：特休天數與未休折算、病假半薪等假別、變形工時、抽成規則。目前請用老闆頁的「薪資調整」處理，並寫明原因。
- **國定假日的夜班**：跨午夜的班整班算在上班那天，所以國定假日當晚開始的夜班會整班加倍；前一天晚上開始、跨進國定假日凌晨的那段不會加倍。如果你的約定不同，請用「薪資調整」補差額。
- **女性夜間工作**：勞基法第 49 條對女性在晚上 10 點到隔天早上 6 點工作有規定（例如要提供交通工具或宿舍），系統不會檢查，請自行確認。
- **功能開關只是把選單藏起來**：關掉的模組不會出現在選單上，但資料表還在。
- 以上建議原則上僅供參考，實際適用請依你的勞動契約、工作規則與主管機關解釋。

## 怎麼開始

```bash
python setup.py
```

第一題選最接近你的產業範本，之後在 `config/store.toml` 改單位（例如「堂」「隻」「台」）、支出類別、功能開關。想新增產業範本，複製 `presets/` 底下的一個資料夾來改，歡迎送 PR。
